# soundfont/

The per-note mp3 samples `@caller/music`'s player loads through abcjs' synth,
self-hosted so nothing streams from GitHub at run time. Generated by
`scripts/build-soundfont.mjs` (`pnpm --filter @caller/web soundfont`), which
downloads only the notes the bundled tunes need and writes `manifest.json`;
`src/soundfont.test.mjs` checks the manifest against the tunes.

Source: FluidR3_GM by Frank Wen, MIT licence, rendered to per-note mp3s by
[gleitz/midi-js-soundfonts](https://github.com/gleitz/midi-js-soundfonts)
(MIT), served at paulrosen.github.io — abcjs' own default soundfont.
